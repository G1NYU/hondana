# Shelf Feature Plan

This branch introduces an experimental Shelf feature for Mihon.

## Goal
Add a new neo-otaku style Shelf tab to Mihon while preserving the existing reader, library, and extension ecosystem.

## Planned capabilities
- Shelf home screen with cinematic hero
- Sections for Manga, Manhwa, Music, and Books
- AniList-powered favorites and lists
- Last.fm-powered albums, artists, and recent tracks
- Open Library-powered books
- Spotlight panel / bottom sheet details
- Tag filters and future personalization

## Notes
This is an initial scaffold branch intended to prepare the implementation structure before wiring it into Mihon's navigation.
